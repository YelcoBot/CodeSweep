## Dependencias entre proyectos

```
Vsix ──► Infrastructure.VisualStudio ──► Infrastructure.Roslyn ──► Application ──► Domain
  └──────────────────────────────────────────────────────────────►┘
```

- **Domain**: no conoce a nadie.
- **Application**: solo Domain. Define los puertos.
- **Infrastructure.Roslyn**: implementa `ICodeCleaner`. Depende de Roslyn, no de VS.
- **Infrastructure.VisualStudio**: implementa los puertos que necesitan VS.
- **Vsix**: arma el contenedor de DI y expone los botones.

## Botones (menú **CodeSweep**)

| Botón | Caso de uso |
|---|---|
| Cleanup Active Document | `CleanupActiveDocumentUseCase` |
| Cleanup Open Code | `CleanupOpenDocumentsUseCase` |
| Cleanup All Code... | `CleanupSolutionUseCase` |
| Automatic Cleanup On Save | `ToggleCleanupOnSaveUseCase` + `SaveEventListener` |
